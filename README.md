# Hayrullah Demir — Personal Portfolio

A personal portfolio website built to showcase my background, software development journey, projects, technical skills, and community management experience.

The website supports both **Turkish and English**, with a responsive design and a dark visual theme.

## Features

- Bilingual support (Turkish and English)
- Responsive design for desktop, tablet, and mobile
- Dedicated About, Projects, Skills, and Contact pages
- Smooth scroll reveal animations
- Dark-themed interface
- Language switching while preserving the current page

## Tech Stack

- **Next.js**
- **React**
- **TypeScript**
- **Tailwind CSS**
- **Git & GitHub**

## Getting Started

Clone the repository:

```bash
git clone https://github.com/hdmr53/hayrullahdemir.git
```

Navigate to the project directory:

```bash
cd hayrullahdemir
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
